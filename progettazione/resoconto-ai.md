
# Resoconto dell'utilizzo dell'AI — Esercitazione 8

## Sessione 1 — Organizzazione dei dati

- Ho utilizzato ChatGPT per comprendere la struttura dei file JSON e il collegamento tra eventi e sedi.
- Ho completato i sei eventi e le tre sedi partendo dai contenuti del sito Segnale.
- Ho verificato che ogni evento avesse un identificativo, una data, un orario, una descrizione e il riferimento alla sede corretta.
- Ho mantenuto i contenuti e le scelte grafiche del sito già realizzato.

## Sessione 2 — Programma dinamico

- Ho chiesto all'AI come sostituire le schede HTML statiche con contenuti generati automaticamente.
- Ho inserito il codice JavaScript che utilizza fetch per leggere eventi.json e sedi.json.
- Ho avuto bisogno di chiarimenti per individuare le righe da sostituire senza cancellare altre parti della pagina.
- Ho verificato il risultato con Live Preview, controllando che comparissero tutti e sei gli eventi e le relative immagini e sedi.
- Ho imparato che per leggere correttamente i file JSON serve utilizzare un server locale invece di aprire direttamente il file HTML.

## Sessione 3 — Meteo e schema dei dati

- Ho utilizzato ChatGPT per aggiungere il meteo attuale di Torino tramite l'API Open-Meteo.
- Ho inserito il codice nella pagina info.html mantenendo la galleria fotografica e la mappa.
- Ho verificato che temperatura, vento e orario del rilevamento fossero visualizzati correttamente.
- Ho completato SCHEMA.md con le informazioni sui dati e il diagramma Evento–Sede in Mermaid.
- Ho verificato che il diagramma fosse leggibile nell'anteprima Markdown di Visual Studio Code.

## Considerazioni

L'intelligenza artificiale mi ha aiutata soprattutto a comprendere dove intervenire nel codice e come collegare i diversi file.

Ho applicato le modifiche gradualmente, controllando i risultati nel browser prima di procedere.

Le spiegazioni passo dopo passo mi hanno permesso di comprendere meglio il funzionamento di JSON, JavaScript, API e GitHub Pages.
